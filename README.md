# Stora Desktop downloads

Get the latest Stora Desktop for Linux or Windows from the [release page](https://github.com/tovmeod/stora-desktop-releases/releases/latest). Open **Assets** to find the download for your system.

<!-- GENERATED:INSTALL:START -->
## Ubuntu and Linux (64-bit)

1. Download the file ending in `_amd64.AppImage`.
2. In Ubuntu Files, right-click the download, open **Properties → Permissions**, and allow it to run as a program.
3. Open the file. If the setup window appears, click **Install**. Stora opens after setup and appears in **Show Apps**. Older AppImages open Stora directly. Keep those files in a folder you own if you use in-app updates.

Requires glibc 2.35 or newer, such as Ubuntu 22.04 LTS or later.
<!-- GENERATED:INSTALL:END -->

<!-- GENERATED:INSTALL-WINDOWS:START -->
## Windows (64-bit)

1. Download the file ending in `_x64-setup.exe`.
2. Open the installer and follow its prompts.
3. Open **Stora Desktop** from the Start menu.

Windows may show a SmartScreen prompt because the installer is unsigned. Check that you downloaded it from the official release page before continuing.
<!-- GENERATED:INSTALL-WINDOWS:END -->

Stora Desktop checks for updates in the app. `latest.json` is the feed used by the updater.
